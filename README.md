# E-Commerce-Dashboard
Dashboard E-commerce Sales ini menyajikan metrik utama seperti total transaksi, total penjualan, dan pelanggan unik, dilengkapi analisis penjualan per kategori, top 10 produk terlaris, tren penjualan harian, segmentasi pelanggan, serta distribusi penjualan per negara untuk mendukung insight bisnis yang cepat dan jelas.
