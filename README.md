Saya membuat dashboard E-commerce Sales yang menampilkan ringkasan kinerja penjualan secara komprehensif, meliputi total transaksi, total sales, dan jumlah pelanggan unik sebagai indikator utama performa bisnis. Dashboard ini juga menyajikan analisis penjualan berdasarkan kategori produk, 10 produk dengan penjualan tertinggi, serta persentase penjualan per segmen pelanggan untuk memahami kontribusi tiap segmen. Selain itu, tersedia visualisasi total penjualan harian guna memantau tren waktu dan total penjualan per negara untuk mengidentifikasi performa pasar secara geografis, sehingga dashboard ini mendukung pengambilan keputusan berbasis data secara cepat dan efektif.
